# Fight3D(仮タイトル)

「月蝕の闘技場」を舞台にした 3D 対戦格闘ゲーム。Unity 6.3 LTS で作っています。

## いまできること

- 半径10mの円形ステージ(円の外には出られない見えない壁)
- カゲツ(人形の仮モデル)を WASD で動かせる
- カメラはカゲツの後ろから、サンドバッグの方を向いて追いかける
- U / I / O で 弱攻撃 / 中攻撃 / 強攻撃 攻撃。サンドバッグに当たるとダメージ数字が出る
- 弱 → 中 → 強 の連続技(当たっているとつながる)、パッシブ「連刃」のダメージアップ
- R キーで位置とサンドバッグをリセット
- ガード(J)と回避ステップ(K、無敵あり)
- カゲツのスキル: 影穿ち(P、3連続目は踏み込み+よろけ)、三日月払い(W+P、ガード崩し)、仮面解放(S+P、速度UP+呪印)、ウルト冥月斬(O+P、ゲージ100)
- ウルトゲージ(当てたダメージの10%、ガードされると3)
- サンドバッグ: よろけ・浮き(追い打ち0.7倍)、F1でガードする設定、F2でゲージ満タン
- ゴウガ(F5 でカゲツと切り替え): 通常攻撃(ダメージ1.15倍・出が+2F)、歩く速さ0.85倍、岩砕き(P、衝撃波で浮き)、剛腕引き(W+P、つかんで引き寄せ)、受け止め(S+P、当て身反撃)、ウルト大地崩し(O+P、体力が少ないほど強い)、パッシブ不屈(体力が減ると攻撃力アップ・1回だけ体力1で耐える)
- CPU対戦(F6 でトレーニングと切り替え): 自分が選んでいない方のキャラが CPU。99秒・2本先取、時間切れは体力の割合で判定。R でやり直し
- トレーニング設定: F3 でサンドバッグが殴ってくる(受け止め・ガード・回避の練習用)、F4 で自分の体力を 100% → 50% → 25% → 10% に切り替え
- カゲツとゴウガは本番の3Dモデル(Blender で作成、トゥーン調)で表示され、待機・歩き・技・ガード・回避・やられ・K.O.・勝ちのアニメが動きに合わせて流れる。モデルが無いときは人形の仮モデルになる(2026-11-22 追加)

## 3Dモデルの作り方(Blender)

- モデルは `Art/Blender` のスクリプトで作る: `build_kagetsu.py` / `build_gouga.py`(体・服・顔)、`kagetsu_anims.py` / `gouga_anims.py`(アニメ)、`char_builder.py`(共通の道具)
- 作り直すとき(PowerShell): `& "D:\steam\steamapps\common\Blender\blender.exe" --background --python Art\Blender\build_kagetsu.py`
- チェック: Unity のメニュー「Fight3D/モデルをチェック」(Humanoid・クリップ・シェーダー)と、Test Runner の PlayMode テスト `ModelPlayTest`(CPU同士で30秒試合させ、流れたアニメと画面を `Logs/PlayCheck` に保存)
- 書き出した FBX は `Assets/Models/Characters/Resources/Fighters/` に入り、ゲームが自動で読み込む。読み込むときに Humanoid・クリップ名・ループ・トゥーンのマテリアルが自動で設定される(`Assets/Models/Editor/CharacterModelPostprocessor.cs`)

## 使っているパッケージ

| パッケージ | 用途 | 入れ方 |
| --- | --- | --- |
| Input System | 入力(キーボード・コントローラー) | Package Manager → Unity Registry |
| Cinemachine 3.x | 背後カメラ | Package Manager → Unity Registry |
| LitMotion 2.x | 見た目の動き(揺れ・ダメージ数字など) | Package Manager → + → Install package from git URL → `https://github.com/annulusgames/LitMotion.git?path=src/LitMotion/Assets/LitMotion` |

3つ全部が入るまでゲーム本体(`Assets/Scripts`)はコンパイルされません(`Fight3D.asmdef` の設定)。足りないときは ▶ を押すと案内が出ます。

## 操作

| 操作 | キーボード | コントローラー |
| --- | --- | --- |
| 近づく / 離れる / 回る | W / S / A・D | 左スティック・十字キー |
| 弱 / 中 / 強 攻撃 | U / I / O | X(□) / Y(△) / B(○) |
| スキル1 / スキル2 / スキル3(カゲツ: 影穿ち / 三日月払い / 仮面解放、ゴウガ: 岩砕き / 剛腕引き / 受け止め) | P / W+P / S+P | RB(RT) / 上+RB / 下+RB |
| ウルト(カゲツ: 冥月斬、ゴウガ: 大地崩し) | O+P 同時押し | B+RB(B+RT) |
| ガード / 回避 | J / K | LB(LT) / A(×) |
| リセット | R | START |
| (トレーニング)サンドバッグのガード / ゲージ満タン / サンドバッグが殴ってくる | F1 / F2 / F3 | SELECT を押しながら X / Y / B |
| (トレーニング)自分の体力を減らす / キャラ切り替え | F4 / F5 | SELECT を押しながら A / RB |
| CPU対戦 ⇔ トレーニング の切り替え | F6 | SELECT を押しながら LB |
| (CPU対戦)試合をやり直す / キャラ切り替え | R / F5 | START / SELECT を押しながら RB |

キー配置は `Assets/Resources/FightControls.inputactions` をダブルクリックすると変更できます。

## ファイルの説明(Assets/Scripts)

| ファイル | 役割 |
| --- | --- |
| GameBootstrap.cs | ▶ を押すと場面(ステージ・キャラ・カメラ・表示)を自動で組み立てる。キャラ・モードの切り替え |
| FighterController.cs | 自分のキャラ(カゲツ・ゴウガ共通)の移動・攻撃・ガード・回避・攻撃を受ける |
| Tuning.cs | **調整する数値はすべてここ**(歩く速さ・回避・ゲージ・スキル・サンドバッグ・カゲツとゴウガの技の表) |
| MoveData.cs | 技データの形(どんな項目があるか) |
| CharacterKit.cs | キャラごとに違う部分(技の表・スキル・パッシブ)の土台 |
| KagetsuSkills.cs | カゲツのスキルの回数・使えない時間・仮面解放・連刃 |
| GougaSkills.cs | ゴウガのスキルの使えない時間・不屈・大地崩しの威力 |
| Shockwave.cs | ゴウガの岩砕きの衝撃波 |
| IFightTarget.cs | 攻撃を当てられる相手(サンドバッグ・キャラ)の決まりごと |
| CpuBrain.cs | CPU の頭脳(近づく・連続技・ガード・回避・スキル・ウルト) |
| BattleManager.cs | CPU対戦の試合の進行(ラウンド・99秒・2本先取・K.O.・時間切れ) |
| BattleHUD.cs | CPU対戦の画面表示(体力バー・時間・ラウンド・大きな文字) |
| Sandbag.cs | サンドバッグ(体力・連続技の記録・揺れ・引き寄せられる・殴ってくる設定) |
| CameraRig.cs | 背後カメラ(Cinemachine) |
| TrainingHUD.cs | ダメージ数字と右上・左上の表示 |
| DollBuilder.cs | キャラの見た目を作る。本番の3Dモデルを読み込む(無ければ人形の仮モデル(カゲツ・ゴウガ・サンドバッグ)を図形で作る) |
| CharacterAnimator.cs | 本番の3Dモデルのアニメを、キャラの状態(技・ガード・回避・やられ・移動)に合わせて流す |
| HitFx.cs | 攻撃の演出(当たり・ガードの小さな火花、カゲツの剣の軌跡、衝撃波の土ぼこり)。控えめな大きさ・短い時間 |
| Arena.cs | ステージの大きさと見えない壁 |
| FightInput.cs | 入力(Input System) |

シーンに何も置かなくても、▶ を押せば動きます。

## 進め方の決まり(プロジェクト規則)

1. main に直接保存しない(ブランチ → プルリクエスト → M がマージ)
2. 動かして確認してからマージする。PC の Unity で確認してから次の機能へ進む
3. 仕様を変えたら仕様書(Notion)も直す。元の記述は消さずに追記する
4. 夜間の作業は、M が書いた「やっていい範囲」だけ
5. うまくいかなかった依頼文もメモに残す
6. 名前(クラス・変数など)は英語、コメントは日本語
7. 調整する数値は 1 か所(`Assets/Scripts/Tuning.cs`)に集める
8. 数値は仕様書の値を使う。仕様書に無い値は「仮」と書く
9. 外部パッケージがそろうまでゲーム本体をコンパイルしない(`Fight3D.asmdef`)
10. クラスとメソッドには `/// <summary>`、値を入れる所には `//` で補足を付ける

## コードの決まり

- クラスとメソッドには必ず `/// <summary>` で説明を付ける
- 値を入れる所(フィールド・定数・調整値)には `//` で補足(単位・意味)を付ける
- コメントは日本語で、初めて読む人にも分かる言葉で書く
- 調整する数値は `Tuning.cs` に置き、`[仕様書]`(仕様書の値)か `[仮]`(仮で決めた値)かを書く
- 見た目だけの数値(色・剣の振り方・揺れの大きさなど)は、それぞれのファイルに置いてよい
