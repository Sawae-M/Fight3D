# Fight3D(仮タイトル)

空に浮かぶ円形の闘技場「月蝕の闘技場」を舞台にした、1対1の3D対戦格闘ゲームです。Unity で作っています(開発中)。

## ストーリー

呪いの仮面に取り憑かれた剣士カゲツ。かつての仲間ゴウガは、その仮面を割ってカゲツを取り戻すため、月蝕の闘技場の大会に挑みます。

## キャラクター

| キャラ | タイプ | 特徴 |
| --- | --- | --- |
| カゲツ | 仮面の剣士・手数型 | 素早い連続攻撃が得意。攻撃をつなぐほど威力が上がる |
| ゴウガ | 熊の獣人・粘り型 | 打たれ強く、追い詰められるほど強くなる。逆転が持ち味 |

## 遊び方

- キャラの後ろから見るカメラで、円形のステージを自由に動き回って戦います
- 2本先取で勝ち
- 弱・中・強の攻撃、キャラごとのスキル、ゲージをためて出す必殺技(ウルト)、ガードと回避を使い分けます
- ボタンを組み合わせるだけで技が出る、シンプルな操作です

## 操作

| 操作 | キーボード | コントローラー |
| --- | --- | --- |
| 移動 | W / A / S / D | 左スティック・十字キー |
| 弱 / 中 / 強 攻撃 | U / I / O | X(□) / Y(△) / B(○) |
| スキル | P / W+P / S+P | RB(RT) / 上+RB / 下+RB |
| ウルト | O+P | B+RB(B+RT) |
| ガード / 回避 | J / K | LB(LT) / A(×) |

## モード

- トレーニング(サンドバッグで技の練習)
- CPU対戦
- オンライン対戦(予定)
